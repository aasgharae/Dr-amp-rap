## راه‌اندازی روی GitHub Pages
1. یه repository جدید بساز (Public).
2. همه فایل‌ها رو آپلود کن (Add file > Upload files)، مستقیم توی ریشه، نه داخل پوشه.
3. Settings > Pages > Source: Deploy from a branch > Branch: main و پوشه / (root) > Save.
4. بعد از یکی دو دقیقه آدرس https://USERNAME.github.io/REPO/ آماده می‌شه.
5. با کروم گوشی بازش کن > منو > Install app.
